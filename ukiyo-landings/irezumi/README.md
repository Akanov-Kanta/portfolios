# IREZUMI 入れ墨

Landing page for a (fictional) Japanese tattoo studio, drawn in the flat ukiyo-e / Animatrix "Program" style.
Next.js 16 (App Router) · Tailwind v4 · GSAP ScrollTrigger. All imagery is hand-built inline SVG.

```bash
npm install
npm run dev -- -p 3103   # http://localhost:3103
npm run lint
npm run build
```

See `PLAN.md` for sections, illustrations and motion. Geometry helpers for the dragon/koi bodies live in
`lib/serpent.ts`; the illustrations are in `components/art/`.
