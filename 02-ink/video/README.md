# video — variant B

Scroll-scrubbed frames from a Tokyo Ghoul fan edit by @pzxepitsu (TikTok). Copy lives in `src/content.ts`.

```bash
npm install && npm run dev   # http://localhost:3202
npm run frames               # rebuild public/media/frames from the source mp4
npm run shots                # screenshots + checks (dev server must be running)
```
